# 4. INTRODUCTION

Generative Artificial Intelligence has become an important technology for generating different types of content such as text, code, images, summaries, reports, explanations, and educational materials. Generative AI systems work based on the instructions provided by the user.

An instruction given to a Generative AI system is called a **prompt**. A prompt tells the AI what the user wants it to do. The quality of the prompt can have a significant effect on the quality and usefulness of the generated response.

**Prompt Engineering** is the process of designing, organizing, and improving prompts to obtain the desired output from an AI system.

For example, instead of simply asking:

> "Tell me about AI."

A more useful prompt could be:

> "Explain Artificial Intelligence in simple English for a first-year college student and give three real-world examples."

The second prompt gives more direction to the AI and therefore can produce a response that is better suited to the user's requirement.

Different tasks require different prompting methods. A simple question can use **Straightforward Prompting**, while a comparison can use **Tabular Format Prompting**. Educational exercises can use **Missing Word Prompting**, and complex tasks can use **Preceding Question Prompting** to establish context.

# 6. STRAIGHTFORWARD PROMPTING

## 6.1 Definition

**Straightforward Prompting** is a basic prompting technique in which the user directly tells the AI what task needs to be performed.

The prompt is generally short, clear, and specific. It does not require multiple steps or complicated instructions.

### Basic Structure

**Direct Instruction → AI Response**

The user states the task directly, and the AI generates a response based on that instruction.

---

## 6.2 Example Scenario – Examination Preparation

A college student has an upcoming semester examination and wants some simple preparation tips.

### Prompt

> "Give five simple tips for preparing for semester examinations."

### Expected Output

1. Prepare a proper study timetable.
2. Understand important concepts clearly.
3. Revise the topics regularly.
4. Practice previous examination questions.
5. Take sufficient rest and maintain concentration.

### Explanation

The user has directly specified the required task. There is no need for additional context because the task is simple and understandable.

---

## 6.3 Example Scenario – Learning Generative AI

### Prompt

> "Explain Generative AI in simple words and give three examples."

### Expected Output

Generative AI is a type of Artificial Intelligence that can create new content based on the information it has learned.

Examples include:

1. AI-generated text
2. AI-generated images
3. AI-generated code

This prompt is straightforward because it directly asks the AI for an explanation and examples.

---

## 6.4 Example Scenario – Project Development

A student wants a simple project idea.

### Prompt

> "Give five simple Artificial Intelligence project ideas for college students."

### Expected Output

* AI chatbot
* Student attendance prediction system
* Smart traffic management system
* AI-based recommendation system
* Student performance prediction system

---

## 6.5 Advantages of Straightforward Prompting

### 1. Easy to Use

The user does not need advanced knowledge of Prompt Engineering.

### 2. Saves Time

The user can directly ask the AI instead of creating a complex prompt.

### 3. Suitable for Simple Tasks

It works well for definitions, explanations, lists, and simple questions.

### 4. Easy to Understand

The structure of the prompt is simple and clear.

### 5. Quick Response

The AI can directly process the instruction and generate an answer.

---

## 6.6 Limitations

* The response may be too general.
* Important context may not be included.
* The output format may not be exactly what the user expects.
* Complex tasks may require more detailed instructions.
* Different wording can sometimes produce different responses.

---

## 6.7 Applications

Straightforward Prompting is useful for:

* Definitions
* Simple explanations
* Summaries
* Basic questions
* Brainstorming
* Short suggestions
* Simple content generation

# 7. TABULAR FORMAT PROMPTING

## 7.1 Definition

**Tabular Format Prompting** is a prompting technique where the user instructs the AI to organize information in the form of a table.

A table consists of **rows and columns**, making information easier to read, compare, and analyze.

### Basic Structure

**Task + Required Information + Table Format**

---

# 8. MISSING WORD PROMPTING

## 8.1 Definition

**Missing Word Prompting** is a technique in which one or more words are removed from a sentence, and the AI is asked to identify or complete the missing information.

This technique is particularly useful for educational purposes because it can be used to create quizzes, revision exercises, and knowledge tests.

### Basic Structure

**Incomplete Sentence → Missing Word → AI Completion**

---

## 8.2 Example Scenario – Python

### Prompt

> "Complete the following sentence: Python is a ______ programming language."

### Expected Output

**High-level**

---

## 8.3 Example Scenario – Machine Learning

### Prompt

> "Complete the sentence: In supervised learning, the model is trained using ______ data."

### Expected Output

**Labelled**

---

## 8.4 Example Scenario – Data Science

### Prompt

> "Fill in the blank: ______ is a Python library commonly used for numerical operations."

### Expected Output

**NumPy**

---

## 8.5 Educational Quiz Scenario

A teacher wants to generate a short AI-based quiz.

### Prompt

> "Fill in the blanks:
>
> 1. ______ is a Python library used for data manipulation.
> 2. Machine Learning is a branch of ______.
> 3. ______ is used for numerical operations in Python.
> 4. A ______ is a set of instructions given to an AI system."

2. Artificial Intelligence
3. NumPy

---

## 8.6 Explanation

The AI uses the surrounding words and context to identify the missing word. This allows the technique to be used as an interactive learning method.

Students can use it to test their understanding before examinations.

## 8.7 Advantages

### 1. Useful for Education

Teachers can easily create practice exercises.

### 3. Knowledge Testing

### 4. Easy Quiz Generation

### 5. Revision

Students can use missing-word questions for quick revision.

# 9. PRECEDING QUESTION PROMPTING

## 9.1 Definition

**Preceding Question Prompting** is a technique in which the user asks a related question before providing the main task.

The preceding question helps establish the required context. The information obtained from the first question can then be used to generate a more specific response to the main task.

### Basic Structure

**Preceding Question → Context → Main Prompt → Final Response**

---

### Prompt

### Expected Response

Important skills include:

* Excel
* SQL
* Statistics
* Python
* Data visualization
* Communication
* Problem-solving

---

## Step 2 – Main Prompt

> "Based on these skills, create a six-month learning plan for a beginner."

### Expected Output

| Month   | Focus Area                    |
| ------- | ----------------------------- |
| Month 1 | Excel and basic data handling |
| Month 2 | SQL and databases             |
| Month 3 | Statistics                    |
| Month 4 | Python, NumPy and Pandas      |
| Month 5 | Data visualization            |
| Month 6 | Data analysis projects        |

## Explanation

The first question provides the required background information. The second prompt uses this information to create a learning plan.

If the student directly asks for a learning plan without first identifying the required skills, the response may be more general.

# 16. DIFFERENCE IN APPROACH

The four techniques differ mainly in the way instructions are provided to the AI.

### Straightforward Prompting

The user directly asks the AI to perform a task.

**Example:**

> "Explain Artificial Intelligence."

### Tabular Format Prompting

The user specifies that the output should be presented as a table.

**Example:**

> "Compare AI and Machine Learning in a table."

### Missing Word Prompting

The user provides an incomplete statement.

**Example:**

> "Machine Learning is a branch of ______."

### Preceding Question Prompting

The user first asks a related question and then provides the main task.

**Example:**

> "What skills are required for Data Science? Based on these skills, create a learning plan."

# 18. BEST PRACTICES FOR PROMPT ENGINEERING

To obtain effective AI responses, the following practices should be followed:

### 1. Be Clear

The prompt should clearly state what is required.

### 2. Provide Context

Relevant background information should be included when necessary.

### 3. Specify Output Format

If the user needs a table, list, paragraph, or steps, it should be clearly mentioned.

### 4. Keep Instructions Relevant

Unnecessary information should be avoided.

### 5. Break Complex Tasks

Large tasks can be divided into smaller questions.

### 6. Review the Response

The generated answer should be checked for relevance and correctness.

### 7. Refine the Prompt

If the response is not satisfactory, the prompt can be modified and tried again.

### 8. Verify Important Information

AI-generated information should be verified before being used in important academic or professional work.
